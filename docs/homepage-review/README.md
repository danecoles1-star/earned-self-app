# Homepage and Home Screen update review

Prepared 2026-11-09 on `release/homepage-install-update`, based on merged PR #8 main commit `957a7ba8a12964b12f71f6aa3fa7bfd50d8bfb7f`.

## Scope

Integrated only the supplied package's new homepage, homepage CSS, manifest, logo icons, HTML install metadata, manifest MIME support in the local production test server, and related tests/documentation. A narrow-screen spacing fix reduces example-tab padding at widths up to 360px, eliminating the supplied layout’s 4px horizontal overflow at 320px. The full package was compared against its earlier version before integrating the delta. Existing PR #8 fixes in App.tsx, the lockfile, security headers, authentication, and database remain intact.

The homepage's AI-prepared experience copy is intentionally retained with owner approval. AI is not connected by this release; public invitations remain on hold until AI and the other launch requirements are ready.

The normal Playwright Chromium download failed in this environment: the CDN returned a short HTML “Site Unavailable” response instead of the ZIP. Test selector changes preserve the original onboarding checks. The old homepage classes were replaced with the new hero/example classes. The image-load assertion in design-surfaces now polls until every rendered image is loaded, avoiding a race while retaining the zero-broken-image requirement. The six new homepage tests cover light/dark at 320, 390 and 1440px, inert sample screens, example switching, CTA visibility, overflow, manifest/icons, and Make it mine → onboarding.
